# teigeodata for Go

```sh
go get github.com/teispace/teigeodata/bindings/go
```

Go 1.26 or later. The package calls the C library (`libteigeodata`) through cgo, or through
[purego](https://github.com/ebitengine/purego) when built with `CGO_ENABLED=0`, and loads it
at run time: the file passed to `teigeodata.LoadLibrary`, then the file `TEIGEODATA_LIB`
names, then the release's prebuilt library fetched into the user cache, then the system's
library path (an installed [C package](../c)). Fetch the prebuilt library once with

```sh
go run github.com/teispace/teigeodata/bindings/go/cmd/teigeodata-fetch
```

or from code with package `fetch`; it is checked against the SHA-256 this module pins.

```go
engine, err := teigeodata.NewEngine()
if err != nil { ... }
defer engine.Close()
if _, err := engine.OpenFile("np.tgd"); err != nil { ... }
blob, err := engine.Search("Kathmandu", 5)
r, err := teigeodata.NewReader(blob)
names, err := r.Strings("name")
lats, err := teigeodata.Values[float64](r, "lat")
```

Every failure is an `*teigeodata.Error` with a stable code: `errors.Is(err,
teigeodata.CodeMissingComponent)`. Handles may be used from any goroutine. Design and
measurements: [D-297](../../docs/03-decisions/log.md).

## Testing

```sh
cargo build --release -p teigeodata-c
TEIGEODATA_LIB=$PWD/../../target/release/libteigeodata.so go test -race ./...
CGO_ENABLED=0 TEIGEODATA_LIB=... go test ./...
```

The binding is generated by `cargo xtask bindings` from `xtask/templates/go*.j2`, except
`support.go`, `load.go`, `reader.go`, `dl_*.go`, `doc.go`, `fetch` and `internal/prebuilt`.
