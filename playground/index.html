Playground

Every query, in your browser

The WebAssembly engine and a released pack, run in this tab. Search as you type, click the map for what is at a point, open a place for its hierarchy and outline, measure, list what is within a radius. Each answer shows its code and how long it took.

  • Every query runs here. Only the map's tiles come from OpenStreetMap; turn them off for none.
  • Checked. The pack's SHA-256 is checked before it opens; the engine checks each section it reads.

The same calls work in an app: see in the browser and the reference.
