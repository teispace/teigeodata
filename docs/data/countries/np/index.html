Names

Languages (BCP 47): ne, en, new. Scripts (ISO 15924): Deva, Latn, Newa. Names with no Latin spelling are romanised by ne-Deva; names missing in a script are written by ne-Latn-Deva and marked as transliterations, never canonical.
