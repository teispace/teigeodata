# Phase 5: boundary and bindings

**Goal:** every major language calls the same engine and sync API with the same answers:
C/C++, Swift, Kotlin and Java (Android and desktop), Dart and Flutter, Python, Node, the
browser and other WASM hosts, .NET and Go. Each ships as its ecosystem expects. Exit:
milestone **M5** ([roadmap](../roadmap.md)).

**Research:**
- [bindings, packaging, CI and MCP](../../02-research/notes/bindings-and-mcp.md): the
  strategy per target, packaging, release pipeline, spikes S1 to S9 (2026-11-06);
- [spike S4](../../02-research/notes/bindings-spike-s4.md) and its
  [results](../../02-research/benches/s4-bindings.md): a hand-written safe API crate
  (`teigeodata-api`), the IDL extracted from it with `syn`, every mechanical layer generated by
  `cargo xtask bindings` with a drift check, results as one columnar blob (`teigeodata-blob`);
  six functions reach C, Swift, Dart, Python, Node and the JVM through one parity suite
  (2026-11-07, D-065);
- [ADR-0016](../../03-decisions/adr/ADR-0016-bindings.md): own C ABI, IDL and generators.

Order: the API surface first, since every language is a projection of it. Then the C ABI and
its gates, then the targets in the order the first consumers need them (mobile and Flutter,
then the JVM, then Python, the web and the rest). Each target is done when it installs from its
own package format, passes the parity suite and has its benchmark row. Nothing names a country
(P16); the network stays behind the `sync` feature and an explicit call (ADR-0012).

### 5.1 The API surface
- [ ] `teigeodata-api` over the engine: open layers (bytes and files, components, parts),
  `get`, `search` and its options, `reverse`, `near`, `within_radius`, `admin_at`, `tz_at`
  and `tz_of`, the zone rules, `elevation_at`, `iso_code` and `by_iso`, postal codes,
  `parent`, `ancestors`, `children`; every result as a blob, every error typed.
  Done so far: the `Engine` handle with `open_file`, `open_bytes` (each giving a layer ID),
  `remove`, `layers`, `get`, `search`,
  `reverse`, `admin_at`, `parent`, `ancestors`, `children`, `nearby`, `within_radius`, `tz_at`,
  `by_iso`, `elevation_at`, `postal_lookup`, `postal_prefix`, `postal_codes_of` and
  `postal_at`, in every language, checked on `bindings/fixtures/synth.tgd`
- [ ] `teigeodata-api` over sync: the store (init, refresh, catalog, find, locate, install,
  update, remove, pin, repair, status) as jobs with progress callbacks and cancellation
- [ ] The IDL extended for what the surface needs (handles, enums, options structs, jobs), with
  a schema version; the drift check covers every generated file. Done so far: format 2 with
  handles, methods, `&[u8]` and handle parameters

### 5.2 The C ABI and its gates
- [ ] Generated `teigeodata-ffi` and `teigeodata.h` for the whole surface: opaque handles,
  ownership rules, no panic across the boundary, the last-error accessor
- [ ] Gates: ABI compatibility against the last release, the header against cbindgen, the
  drift check, symbol visibility; each proven on a planted break
- [ ] Packaging: shared and static libraries per platform, the header, pkg-config and CMake
  config, on GitHub Releases

### 5.3 Swift
- [ ] Wrapper generated over the C ABI; an XCFramework as a SwiftPM `binaryTarget`; the
  privacy manifest; iOS, macOS and the simulators in CI

### 5.4 Android and the JVM
- [ ] One generated JNI layer: the AAR (cargo-ndk, the 16 KB ELF gate in CI) and the desktop
  JAR with native libraries per OS and architecture; `noCompress` for bundled packs

### 5.5 Dart and Flutter
- [ ] Generated `@Native` bindings with `NativeFinalizer`; a build hook that downloads verified
  prebuilt libraries, building from source as the fallback; Android, iOS, macOS, Windows,
  Linux, and the web through the WASM build

### 5.6 Python
- [ ] Generated PyO3 module; abi3 wheels (3.10 and later) and abi3t for free-threaded
  builds; the blob through the buffer protocol; a free-threading stress test

### 5.7 Node and WASM
- [ ] napi-rs package with per-platform prebuilds; the WASM build with wasm-bindgen per feature
  variant, a size budget per variant (S3), browser, Deno, Bun and Workers

### 5.8 .NET, Go and C/C++
- [ ] .NET over the C ABI with source-generated P/Invoke, NativeAOT-safe, as a NuGet package;
