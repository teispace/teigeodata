# Phase 5: boundary and bindings

**Goal:** every major language calls the same engine and sync API with the same answers:
C/C++, Swift, Kotlin and Java (Android and desktop), Dart and Flutter, Python, Node, the
browser and other WASM hosts, .NET and Go. Each ships as its ecosystem expects. Exit:
milestone **M5** ([roadmap](../roadmap.md)).

**Research:**
- [bindings, packaging, CI and MCP](../../02-research/notes/bindings-and-mcp.md): the
  strategy per target, packaging, release pipeline, spikes S1 to S9 (2026-11-06);
- [spike S4](../../02-research/notes/bindings-spike-s4.md) and its
  [results](../../02-research/benches/s4-bindings.md): a hand-written safe API crate
  (`teigeodata-api`), the IDL extracted from it with `syn`, every mechanical layer generated by
  `cargo xtask bindings` with a drift check, results as one columnar blob (`teigeodata-blob`);
  six functions reach C, Swift, Dart, Python, Node and the JVM through one parity suite
  (2026-11-07, D-065);
- [ADR-0016](../../03-decisions/adr/ADR-0016-bindings.md): own C ABI, IDL and generators.

Order: the API surface first, since every language is a projection of it. Then the C ABI and
its gates, then the targets in the order the first consumers need them (mobile and Flutter,
then the JVM, then Python, the web and the rest). Each target is done when it installs from its
own package format, passes the parity suite and has its benchmark row. Nothing names a country
(P16); the network stays behind the `sync` feature and an explicit call (ADR-0012).

### 5.1 The API surface

  `get`, `search` and its options, `reverse`, `near`, `within_radius`, `admin_at`, `tz_at`
  and `tz_of`, the zone rules, `elevation_at`, `iso_code` and `by_iso`, postal codes,
  `parent`, `ancestors`, `children`; every result as a blob, every error typed.
  Done so far: the `Engine` handle with `open_file`, `open_bytes` (each giving a layer ID),
  `open_file_with` and `open_bytes_with` (`OpenOptions`: priority, verification, loading,
  outline level and tolerance, components, languages), `remove`, `layers`, `get`, `search`, `search_with` (focus
  options as a record),
  `reverse`, `admin_at`, `parent`, `ancestors`, `children`, `nearby`, `within_radius`, `tz_at`,
  `by_iso`, `elevation_at`, `postal_lookup`, `postal_prefix`, `postal_codes_of` and
  `postal_at`, in every language, checked on `bindings/fixtures/synth.tgd`; `tz_of` and
  `iso_code` as every place row's `tz` and `iso` columns; the zone rules (`tz_offset_at`,
  `tz_local`, `tz_zones`, `tz_rules_start`, `tz_version`) on `bindings/fixtures/tz.tgd`
  (D-284). Done 2026-11-14
- [x] `teigeodata-api` over sync: the store (init, refresh, catalog, find, locate, install,
  update, remove, pin, repair, status) as jobs with progress callbacks and cancellation
  ([research](../../02-research/notes/store-api.md)). Done so far: the policy moved from the
  command line into `teigeodata_sync::client`, the CLI on top (its tests unchanged); progress
  and cancel as a watched transport (`teigeodata_sync::watch`); the `Store` and `Job` handles
  in every language (D-279: `create`, `open`, `catalog`, `status`, `pin`, `remove`, `engine`,
  `find`, `locate`;
  `refresh`, `install`, `update`, `repair` as jobs with progress, wait, cancel and result),
  behind the default `store` feature; the asynchronous form of every blocking call in every
  language (D-280, D-281); the platform downloads pass as `install_pass` (D-184, D-282).
  A job's progress stream and cancel in every language (D-283). Done 2026-11-14
- [x] The IDL extended for what the surface needs (handles, enums, options structs, jobs), with
  a schema version; the drift check covers every generated file. Done so far: format 2 with
  handles, methods, `&[u8]` and handle parameters; format 3 with records of scalar fields
  (D-276), the C header check comparing struct fields; format 4 with enums (D-277); format 5 with

  calls (D-280) and the checked `# Job` contract (D-283). Done 2026-11-14

  ownership rules, no panic across the boundary, the last-error accessor. Built through 5.1:
  every generated function runs in `abi::call` or `abi::free`, which catch a panic

- [x] Gates: ABI compatibility against the last release, the header against cbindgen, the
  drift check, symbol visibility; each proven on a planted break

  and the lite library in CI). Done 2026-11-14
- [x] Packaging: shared and static libraries per platform, the header, pkg-config and CMake
  config, on GitHub Releases. Built ([research](../../02-research/notes/c-packaging.md),

  `c-package.yml` on six targets attaches the archives to a `v*` release. Done 2026-11-14
  (green on all six)
