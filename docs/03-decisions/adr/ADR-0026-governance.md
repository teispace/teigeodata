# ADR-0026: Open-source governance

Status: accepted, 2026-11-06

## Context

An open project needs clear rules for contributors and maintainers.

## Decision

Contributor Covenant 3.0; Developer Certificate of Origin sign-off (no CLA); [GOVERNANCE.md](../../../GOVERNANCE.md) with maintainers per area and country; CODEOWNERS; RFCs for format, API and data-model changes; private vulnerability reporting ([SECURITY.md](../../../SECURITY.md)); data corrections with evidence.

## Consequences

- Guides in `docs/09-guidelines/`.

## Alternatives considered

A CLA (heavier for contributors).
