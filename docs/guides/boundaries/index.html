Outlines

A unit's outline as GeoJSON at a level of detail, ready for MapLibre, Leaflet, OpenLayers, Shapely or Turf.

Every example ran

Each snippet is cut from one program per language, the tour, which CI runs on the released pack world-np-lite.tgd (data-2026.11.14.3) and checks line by line against the output shown. The output is the same in every language. Pick your language once: every page remembers it.

boundary answers a unit's outline as one row: geojson, an RFC 7946 Feature (a Polygon or MultiPolygon, outer rings counterclockwise and holes clockwise, seven decimals as stored), with the lod read, its tolerance_m and the number of vertices. A place with no outline answers its point as the geometry; an unknown ID answers no row.

Engine::boundary decodes the outline into an Outline you reuse (its rings, points and tolerance_cm) and returns the layer that held it; Outline::write_geojson writes the same GeoJSON every binding answers. Engine::boundary_vertices counts vertices without decoding.

The Feature goes to a map as it is: MapLibre's and Leaflet's GeoJSON sources, OpenLayers, Shapely's shape(), Turf and JTS all read it.

  • Level of detail. lod 0 is full resolution; 1 to 6 are coarser, each within its tolerance_m, with neighbouring units still sharing their borders at every level. A pack stored at full resolution only (the lite packs) answers every level as 0. A country at level 0 can be megabytes: draw a coarser level, and keep 0 for measuring.
  • lod above 6 is InvalidArgument; a pack installed without boundaries is MissingComponent.
  • Whether a point is inside a unit is admin_at, which tests the same outlines without building them.
