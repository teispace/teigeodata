MCP tools

Every tool and resource of tgd mcp with its arguments and answer, generated from the server's own definitions.

What tools/list and resources/templates/list give, with the bounds of a server's default limits. Every answer is structured content that its tool's output schema accepts, the same object as text, with the attribution under _meta too. How to run the server and connect a client: MCP server.

The server's instructions to a client:

Offline place data. Find places by name with search, by coordinates with reverse and admin_at, around a place with nearby; climb with hierarchy and descend with children. Places are named by IDs such as tgd:np/1xhb: pass them to get_place, lookup, nearby, timezone or read teigeodata://place/{id}. Coordinates are WGS84 degrees, distances metres, heights metres above EGM2008. A long answer has a next_cursor: call the same tool with only cursor for the next page. Show the attribution of an answer wherever its data is shown: the licences require it.

search

Search places by name. Places matching a name, best first. "Name, Parent" ranks places under a parent of that name first. focus ranks places near a point higher (scale_km: how far counts as near, default 50). strict ranks by how well the name matched (exact, then loose, prefix, one edit) before importance and nearness.

Hints: read-only, idempotent.

ArgumentTypeRequiredWhat
querystringyesThe name, in any script, such as Pokhara or पोखरा. 1 to 256 bytes.
cursorstringThe next_cursor of the previous page; the other arguments are then taken from it.
focusobject
focus.latnumberyesLatitude, WGS84 degrees. -90 to 90.
focus.lonnumberyesLongitude, WGS84 degrees. -180 to 180.
focus.scale_kmnumberOver 0; default 50.
limitintegerHow many results, the page's size. 0 to 50; default 10.
strictbooleanRank by match quality first. Default false.

Answers places, a page at a time.

install

Install packs. Downloads packs from the catalog into the store, verified, and serves them: packs as catalog paths or addresses (np, np.places, ae-du), components (every one when none). The person confirms the download's size when the client can ask; otherwise the call is refused past max_bytes (default 100 MB), naming the size. Answers a task, or a handle for install_status.

Listed only by a server over a store that allows installs (--allow-install).

Hints: changes the store, idempotent, reaches the network.

ArgumentTypeRequiredWhat
packsarray of stringyes1 to 16 items.
componentsarray of string
max_bytesintegerThe most this call may download without the person's confirmation; default 100,000,000. At least 0.

Places

The answer of every place tool: a page of results, the next_cursor of the next page when there is one, and the attribution of the packs that answered. A field a place lacks is left out or null.

FieldTypeWhat
attributionstring or nullThe credits of the packs that answered: show them wherever the data is shown.
resultsarray of object
results[].admin_levelinteger1 for a country's first-level units, deeper units after; 0 for a country and for a place that is not an admin unit.
results[].elevationinteger or nullMetres above EGM2008.
results[].idstringIts stable ID, such as tgd:np/1xhb.
results[].kindstring or nullIts kind, such as settlement or admin.
results[].namestring or nullIts canonical name.
results[].parentstring or nullIts parent's ID; null for a root.
results[].timezonestring or nullIts IANA timezone, such as Asia/Kathmandu.
results[].bearingnumberDegrees clockwise from north, from the place to the point asked about.
results[].elevation_sourcestringWhere the height came from: surveyed or model, when stated.
results[].insidebooleanWhether the point asked about is inside the place's outline (reverse).
results[].is_dstbooleanWhether daylight saving time is in force at that instant.
results[].iso_codestringIts ISO 3166 code, for a country or unit that has one.
results[].latnumberLatitude, WGS84 degrees.
results[].lonnumberLongitude, WGS84 degrees.
results[].metersnumberDistance from the point or place asked about, metres.
results[].namesarray of objectEvery name, canonical first (get_place with names).
results[].names[].machinebooleanMade by a machine (a romanisation, a transliteration or a donor label): an app may show it differently.
results[].names[].originstringWhere the name came from.
results[].names[].textstring

results[].names[].langstringA BCP 47 tag, such as ne-Deva.
results[].populationintegerIts number of people, when known.
results[].population_kindstringWhere the number came from: stated (a source's count) or modelled (a population grid over an admin unit).

results[].utc_offsetstringThe UTC offset at the instant asked, such as +05:45 (timezone).
