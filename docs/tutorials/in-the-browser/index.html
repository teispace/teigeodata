In the browser

Run the WebAssembly engine in a page or a Web Worker, cache the pack for offline visits, and answer every query locally.

teigeodata-wasm is the engine compiled to WebAssembly: the same calls as the Node.js package, at most 256 KiB gzipped, or 150 KiB without name search. A page has no file system, so it opens a pack from its bytes; after that one download, every query runs locally. The playground is this package in a page.

Install

Install the package as the install page shows (the Browser tab). Bundlers (Vite, webpack, esbuild) treat the .wasm file as an asset, and the package's exports pick the right entry for browsers, Node.js, Deno and Cloudflare Workers.

Keep the pack for offline visits

Serve the pack with a long Cache-Control and a content hash in its name, or keep it in the Cache API or the origin private file system (OPFS), so a later visit opens it with no network.

Opening copies the bytes into the module's memory once; queries then take microseconds. For a pack of tens of megabytes, open it in a Web Worker so the page stays responsive while it loads.
